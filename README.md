# 🏥 Healthcare Overview Dashboard | Power BI

## 📌 Project Overview

The **Healthcare Overview Dashboard** is an interactive data analytics project developed using Microsoft Power BI to analyze patient demographics, hospital admissions, operational efficiency, and financial performance.

The dashboard transforms healthcare data into meaningful visual insights through interactive charts, KPI cards, and trend analysis. It helps users explore patient characteristics, monitor hospital activity, understand billing performance, and identify patterns across healthcare departments.

## 🎯 Project Objectives

- Monitor key healthcare performance indicators.
- Analyze patient demographics, age groups, gender, blood groups, and medical conditions.
- Evaluate hospital bed utilization and department-wise admissions.
- Analyze billing amounts, insurance coverage, and payment status.
- Track admission, readmission, and discharge trends.
- Present healthcare data through interactive and easy-to-understand visualizations.

## 📊 Dashboard Pages

### 1. Overview
- Total patients and admissions.
- Emergency admissions.
- Total billing amount.
- Average length of stay.
- Patient admission trends.
- Department-wise admission analysis.
- Medical condition distribution.

### 2. Patient Analytics
- Patient distribution by age group.
- Gender distribution.
- Blood group analysis.
- Patient distribution by medical condition.

### 3. Hospital Operations
- Bed utilization by hospital ward.
- Admissions by department.
- Average length of stay by department.
- Patient discharge status analysis.

### 4. Financial Analytics
- Billing amount by department.
- Insurance coverage versus out-of-pocket expenses.
- Payment status distribution.
- Monthly billing trends.

### 5. Trends & Insights
- Monthly readmission trends.
- Readmissions by department.
- Monthly discharge trends.
- Admission and discharge pattern analysis.

## 💡 Business Value

This dashboard demonstrates how healthcare data can be used to:

- Monitor hospital activity and patient distribution.
- Compare department performance.
- Understand bed utilization and patient stay duration.
- Examine billing, insurance, and payment patterns.
- Identify trends that may support operational planning and resource allocation.

The dashboard is intended for analytical and educational purposes, not for clinical diagnosis or treatment decisions.

## 🚀 How to Use

1. Clone or download this repository.
2. Install [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. Open the `.pbix` file.
4. Navigate through the dashboard sections.
5. Explore the visualizations and available filters.
